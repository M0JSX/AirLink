# Changelog

## 0.3.0
- Installers: Windows (Inno Setup), macOS universal .app + DMG, Linux .deb (amd64/arm64)
- App icon, embedded Windows resources
- GitHub Actions: CI on all platforms, tagged releases publish installers

## 0.2.0
- Cross-platform GUI (egui): call/answer, codec settings, device pickers, meters, live stats
- Headless mode (`--headless`) for servers and racks

## 0.1.0
- Two-way P2P link: Opus CELT low-delay or 24-bit PCM over UDP
- Redundancy, adaptive jitter buffer with PLC and drift correction
